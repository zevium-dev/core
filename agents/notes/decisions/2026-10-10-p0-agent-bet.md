## Decision

Moved to P0:

1. **x402 keyless rail** — x402/MPP via Stripe funds an ephemeral wallet session ([dual rail](2026-10-10-dual-rail-keys-and-x402.md)). Feature: [machine-payments](../features/machine-payments.md).
2. **Agent distribution** — `llms.txt`, OAuth on `/mcp` (claude.ai connector), Claude Connectors Directory submission, official MCP Registry listing, one-click installs. Feature: [agent-surface](../features/agent-surface.md).
3. **Capability routing** — agents call a capability; Zevium picks the provider by price/success/latency with fallback and a max-cost cap. Feature: [capability-routing](../features/capability-routing.md). Was P2 #22.
