# Codebase audit — gateway

> Date: 2026-10-10 · Read-only audit
> Scope: `apps/gateway/src` (7,210 LOC), `apps/gateway/test` (6,425 LOC), wrangler configs, gateway-facing `packages/shared/src` (`openapi.ts`, `registry-sync.ts`, `public-claims.ts`, `registry-v2-vectors.ts`). Cross-checked Convex callers where the gateway contract depends on them.

## TL;DR

- Core is sound: wallet DO reserve/settle/refund model, settlement outbox + poison bisection, header hygiene, idempotency scoping, tri-state key verify, pipeline ordering. Fuzz-tested. Keep.
- Around the core: ~1.7k LOC dead or duplicated, plus three hot-path violations and a handful of real billing bugs.
- Worst finding: every authenticated `/gateway` and MCP `call_api` request makes an RPC to **one global** `ControlDO` (`index.ts:195-205`, `pipeline.ts:142-147`). Nothing in production ever writes to it, so it always returns `null`, which means "allowed". You pay latency and hit a global throughput ceiling for zero behavior.
- Registry v2 has a Convex producer that posts to `/internal/registry/v2/events` (`convex/registrySync.ts:798-801,905`). The gateway only routes `/internal/registry/v1/` (`index.ts:309-314`), so every v2 event 404s and retries until it dead-letters. The receiver half is unbuilt. The v1 receiver that does exist has no producer.
- Recommendation: **prune and restructure in place**, don't rebuild blank. Rewrite `index.ts`, `pipeline.ts`, `spec-source.ts`, `catalogue-source.ts`, `discovery.ts`, and `usage.ts`. Keep and refactor `wallet.ts`. Delete `control.ts`.

## Over-engineering (not needed at launch)

- **Claim scanner at the edge**: `public-claims.ts` has 1,887 LOC of confusable-skeleton lexical filtering. It runs in `pipeline`, `mock`, `mcp` (x3), `discovery`, `catalogue-source`, and `spec-source` parse. Publish-time enforcement in Convex is enough because published versions are immutable.
- **Deployment proof in `/health`**: regex matrix over git SHA, CF version UUID, tag formats, and microsecond timestamps (`index.ts:82-116`), plus 169 LOC of tests. CI does use `/health` (`deploy-production.yml:186`, `preview.yml:323`). Keep "ok + release", drop the tag-grammar policing.
- **`#persist` kitchen sink**: 15 optional keys in one transaction (`wallet.ts:560-627`). Each settle rewrites the whole `inFlight` map, the whole terminal map, and every queue partition (`settlement-queue.ts:83-89`). SQLite-backed DO has a real SQL API. Use rows.
- **Usage record shape**: `pendingToUsageRecord` copies 30 fields by hand (`usage.ts:586-650`), and `flushToConvex` copies the same 30 fields again (`wallet.ts:1395-1430`). `KeyBudgetSnapshot` facts (`budgetUsedBefore/ReservedBefore/ReservationCredits`) ride every row for audit nobody reads at zero users.
- **`#mutate` lock + `blockConcurrencyWhile` + reload-on-throw** (`wallet.ts:540-557`): defensible. The lock exists only because sync awaits network inside it (H2). Remove the network-in-lock and most of the need goes away.
- **Registry v2 contract overall** (shared 1,728 + Convex 957 + rollout): canonical-JSON byte caps, per-stream revisions, ACK signatures, bounded-10-row rollout with dual digest chains, for a system with zero users and no receiver. Out of gateway scope to delete Convex side, but the gateway should not adopt it as specified.

## Must survive a rebuild

1. **Wallet balance model**: `available = balance − Σholds`. Zero blocks. Idempotent reserve/settle/refund keyed by reservation id, with a terminal record. Stable `settle:{requestId}` ids (`wallet.ts:1-26,728-1000`).
2. **Checkpoint reconciliation**: monotonic Convex `sequence`; DO balance = checkpoint − unacked pending; per-ref `applied/already_applied/rejected{retryable}` outcomes; lost-ack replay converges (`wallet.ts:1211-1310,1830-1848`).
3. **Poison bisection** for batch ingest: retryable vs blocked vs bisectable singleton (`settlement-queue.ts:160-205`, `usage.ts:106-139`).
4. **Lease expiry** of abandoned holds + alarm-driven maintenance (`wallet.ts:497-508,1805-1836`).
5. **Per-key controls in the DO**: disabled, rotation grace, monthly cap per key family including active holds (`wallet.ts:765-803`).
6. **Header hygiene + idempotency scoping** (`headers.ts`, `idempotency.ts`). Publisher credentials injected after filtering (`pipeline.ts:563-578`).
7. **Tri-state key verify**: outage → 503, never cached as invalid (`key-verifier.ts:115-125`).
8. **Privacy rule**: foreign key on private project → 404, consumer wallet always pays (`pipeline.ts:220-228,301-304`).
9. **Streaming passthrough + client abort propagates to upstream + header timeout** (`pipeline.ts:584-603,819-823`).
10. **MCP `call_api` reuses the pipeline** (no side door) with explicit buffer limits (`mcp.ts:465-491`).
11. **Wallet fuzz test** + sim ledger (`wallet.test.ts:929-1077`, `test/ledger.ts`).

## (2) Prune vs rebuild

**Prune and restructure in place.** No blank rebuild.

- The expensive, subtle part is the wallet/ledger reconciliation: checkpoint sequencing, lost-ack replay, stale-checkpoint adjustment, poison bisection, cap-with-holds. It is correct and fuzz-tested. A blank rebuild re-derives it and re-learns the same bugs.
- Most of the slop is **around** the core: dead control/registry surfaces, three usage transports, four TTL caches, copy-paste admission branches, claim scanning, deploy-proof policing. Deleting it is mechanical.
- But do **rewrite** (not patch) `index.ts`, `pipeline.ts`, the spec/catalogue sources and `discovery.ts`. Their shape blocks x402 (principal), capability routing (admit/forward/finalize split), and token settle (post-stream finalize). Patching keeps the monolith.
- Wallet: keep the semantics, move storage from whole-object KV blobs to SQLite tables (`holds`, `terminal`, `outbox`, `counters`). Move network out of the lock. Add `settle(id, actual)`.
- Precondition: decide the edge registry shape first. The minimal version: one signed snapshot push per route version (compiled route table + public docs) into Cache API/KV, plus a push for top-up/revoke. Without it, H1/H4/H6/B13 and capability routing have no home. Don't build registry v2 as specified.

Target size: ~2.5-3k src LOC (from 7.2k), ~4k test LOC.

## (3) Minimal target module layout

```
apps/gateway/src/
  index.ts                 # router only; one wrapper adds CORS + security headers + request id to every response
  http.ts                  # jsonError, paymentRequired (key + x402 offers), status mapping table
  auth/
    principal.ts           # Principal = {kind:"key", walletId, keyId, familyId} | {kind:"x402", walletId, payer}
    clerk-key.ts           # verify + Cache API + miss limiter; outage → 503
    x402-session.ts        # (P0 next) verify signed wallet session
  routes/
    snapshot.ts            # edge route snapshot per (publisher, project, version): compiled ops, pricing, upstream, headers, capability tags, docs; Cache API/KV; pushed by Convex
  proxy/
    admit.ts               # principal + route + op → Admission {walletId, holdId, holdCredits, pricing}
    forward.ts             # header filter, idempotency scope, upstream safety, timeout, abort, stream or tee
    finalize.ts            # fixed price: settle on 2xx/refund; per-token: parse usage from tee, settle(actual) in waitUntil
    headers.ts  idempotency.ts  upstream-safety.ts
  wallet/
    wallet-do.ts           # reserve/settle(actual≤hold)/release, key controls, in-flight budget; SQLite tables; no network in lock
    outbox.ts              # settlement outbox + poison bisection (from settlement-queue.ts)
    ledger-client.ts       # fetch-only: POST /ingest-usage, GET /wallet-grants
  routing/
    capability.ts          # (P0 next) provider selection from snapshot; fallback on 429/5xx/timeout within cost cap
  surfaces/
    mcp.ts                 # JSON-RPC; call_api → admit/forward/finalize; deliver-or-refund
    mock.ts                # keyless, from snapshot
    discovery.ts           # serves precomputed snapshot index
```

Rules for the layout: nothing in `surfaces/` reaches Convex directly. Only `wallet/ledger-client.ts` and the snapshot pull talk to the control plane. No `convex` npm dependency.
