## Commands

| Command          | What                                                                                                                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm test`      | Workspace Vitest/workerd suites, Convex tests, worktree env-copy tests                                                                                                                             |
| `pnpm typecheck` | Turbo typecheck across workspace                                                                                                                                                                   |
| `pnpm build`     | Turbo build                                                                                                                                                                                        |
| `pnpm ci:pr`     | Format, lint, actionlint, shellcheck, gitleaks, typecheck, tests, root contract/schema/race/paired-Worker checks, one web build with runtime security checks, codegen/route diff, whitespace check |

Run commands through `mise exec -- pnpm ...` when pnpm is not on PATH.
Do not start `pnpm dev` unless requested.

## CI

`ci.yml` runs `pnpm ci:pr` as parallel `quality (<slice>)` matrix jobs, each with
the shared setup action for pinned tools and a frozen install:

| Slice           | Runner | Runs                                                                            |
| --------------- | ------ | ------------------------------------------------------------------------------- |
| `static`        | 2 vCPU | `ci:static`: format, lint, actionlint, shellcheck, gitleaks, typecheck          |
| `test`          | 2 vCPU | `pnpm test`                                                                     |
| `build`         | 2 vCPU | `build:ci`                                                                      |
| `control-plane` | 2 vCPU | `ci:control-plane`: contracts, activation, schema, OCC races, paired acceptance |

Every slice then runs `routes:check` and `diff:check`. The aggregate `ci` job
fails unless every slice passed; it is the check name to require, and the
workflow's conclusion is what `deploy-production.yml` waits on. A new step in
`ci:pr` must also land in a slice.

Turbo cache (`.turbo/cache` via `actions/cache`, per slice): pull requests read
and write it, restoring from their own branch or `develop`. Every other event,
including the `develop` push that gates production, sets `TURBO_FORCE` and runs
uncached (it still writes, which seeds PR caches). `apps/web/turbo.json` adds
root `convex/**` and `contracts/**` to web test/typecheck inputs, since web
imports them by relative path and turbo would otherwise miss those changes.
Why and timings: [decision](../decisions/2026-10-21-ci-parallel-cached-prs.md).

Prettier checks formatting; one root oxlint invocation checks source and scripts,
including `vitest/no-focused-tests`. All Vitest commands use `--allowOnly=false`.
Package test suites run sequentially with at most two Vitest workers each,
avoiding worker oversubscription locally.
TypeScript is aligned to the root version across workspace packages.

`build:ci` builds web once with fixture configuration, then runs the CSRF and
Workerd asset-header checks against that output (`--skip-build`). Standalone
`pnpm --filter web test:csrf-runtime` still builds its own runtime.
`routes:check` fails on changes to committed Convex codegen (rewritten by
`schema:check`) or the route tree generated by the web build. Standalone
`tsr generate` is not used here because it omits TanStack Start declarations
that the Vite build adds. CI initializes an anonymous local Convex
backend with a fixture Clerk issuer; it does not need deployment secrets. Its
`.convex/` runtime state is gitignored and excluded from formatting and tree scans.
Local `routes:check` uses the checkout's configured Convex deployment.

Gitleaks scans full history, the PR/push range, and the current candidate tree.
The tree snapshot excludes ignored local secrets and dependency/build files.
Historical fingerprints remain in `.gitleaksignore`; there is no SHA/count pin.
Actionlint checks workflows and shellcheck checks the remaining shell journeys.

## Browser journeys

`run-all.sh` runs `01-auth.sh`, `02-publisher.sh`, then `03-consumer.sh`.
Publisher and consumer share temporary project fixtures, but each browser lane
has a separate session. Retry workflows set `E2E_SESSION_PREFIX`; the runner
clears inherited session overrides before starting lanes.
`GATEWAY_URL` or `E2E_RUN_PREVIEW=1` adds `00-preview-smoke.sh`.
`E2E_API_KEY` enables the consumer's live gateway, wallet debit, and attribution
assertions. Without it, the consumer checks catalogue and mock behavior.
Set `E2E_EXPECTED_COMMIT` to the exact deployed SHA and provide the test user's
email, password, and OTP. Full browser journeys remain label-gated in previews.

The unused Stripe drill, provider proofs, sanitizer, manifest, and isolated-runner
machinery were removed. Authenticated browser failures report the failing step
in job logs; they no longer capture or upload browser snapshots. Public preview
HTTP contract failures still upload their response evidence.

Keep tests for cross-service identity, metering, cache, and webhook boundaries.
Run `pnpm ci:pr` before opening a PR; commit only when requested.

## Root control-plane gate

`VITEST_MAX_WORKERS=2 pnpm ci:control-plane` checks the frozen 221-entry completion map, offline activation configuration, guarded anonymous schema/codegen, real OCC races, and real local Worker/Convex acceptance using production migration declarations. Local scratch belongs under ignored `.tmp/`; set `TMPDIR` there for full local checks. No shared Convex target or provider configuration is needed. `packages/control-plane-next` and `ci:next` are deleted.

Optional local browser hold: `CUTOVER_BROWSER=1 NEXT_EDGE_ONLY=1 CUTOVER_CLERK_ISSUER=<existing HTTPS Clerk issuer> pnpm test:races` keeps its guarded backend and Worker on port 8787 for up to 30 minutes after HTTP acceptance. The scratch `browser-runtime.json` contains private fixture data, never an artifact; creating `browser-done` there closes both services. Run only the web package's dev server with the loopback Convex URL, localhost gateway, and existing Clerk development credentials. There is no browser auth bypass. Provider-backed payments/webhooks remain an independent owner gate: [runbook](convex-activation.md).

## Dependency compatibility (2026-10-11)

Combined dependency update supersedes #305, #306, #307, #308, and #309. Oxlint 1.86.0 enables React purity/ref/effect diagnostics; fixes use guarded state reconciliation, commit-phase refs, external-store subscriptions, and a stable sidebar skeleton width. No lint rules are disabled. Activity keys only its call-list subtree by filter window, so pagination shares one timestamp per window and filter selects keep focus.

Vitest is split by workspace: root (Convex suite), `apps/web`, and `packages/shared` run Vitest 5.0.3; `apps/gateway` stays on Vitest 4.1.11 because `@cloudflare/vitest-pool-workers` (0.22.0 and latest 0.23.0) declares `vitest`/`@vitest/runner`/`@vitest/snapshot` `^4.1.0`. A gateway probe on Vitest 5.0.3 failed before discovery (`SyntaxError: Unexpected identifier 'file'` inside workerd, zero tests). pnpm resolves each manifest's own Vitest, so the gateway pool sees v4. Bump gateway Vitest when the Worker pool supports v5; do not suppress errors or remove Worker tests.

[v5 migration guide](https://vitest.dev/guide/migration.html) review: no coverage provider, `test.projects`, `sequential` APIs, removed entrypoints, or reporter artifacts are used. `clearMocks` now defaults on; all suites pass with it. `maxWorkers` and `VITEST_MAX_WORKERS` remain supported; scripts cap workers at two. Root Convex config stays explicit (`vitest.convex.config.ts`); workspace suites run from their own package configs.

Counts (files/tests). Baseline `origin/develop` CI: shared 6/105, gateway 15/124, web 79/459, Convex 15/185 = 115/873. After: shared 6/105, gateway 15/124, web 80/461 (+2 highlighter regressions), Convex 16/187 (+2 Stripe SDK regressions) = 117/877. Node script tests unchanged.
