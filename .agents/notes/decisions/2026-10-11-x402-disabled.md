# Disable x402 and retain an enablement runbook

> Date: 2026-10-11 · Status: accepted; deferral effective, enforcement tracked separately · Decided by: owner
> Session: [owner decisions](../sessions/2026-10-11-owner-decisions.md)

## Decision

x402 is **off for now**. Preserve code and accounting history; remove activation from P0 and defer it to P2. P1 #424 tracks enforcing feature-off behavior and the enablement runbook. API-key/org-wallet calls remain the current launch path.

Supersedes activation priority in [dual rail](2026-10-10-dual-rail-keys-and-x402.md) and [P0 agent bet](2026-10-10-p0-agent-bet.md). The built rail is currently gated on bindings, not an explicit default-off switch. This docs-only change does not change deployments or prove they are disabled.

## Future enablement

[Runbook](../architecture/x402-enablement.md) records facilitator selection (Coinbase CDP on Base is a candidate, not a new vendor approval), network/asset, secrets, settlement finality, address normalization, sandbox acceptance and rollback. Revisit those choices before activation. No global revocation path is added by this decision.

Anonymous breakage policy is separately resolved in [breakage revenue](2026-10-11-breakage-revenue.md). Session lifetime and funding-lot expiry remain separate; org funds never expire.
