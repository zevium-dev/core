# CLI supports Node 22 LTS

> Date: 2026-10-13 · Status: accepted; built in #451 review fixes · Decided by: owner

Node >=22.12.0 is chosen to support Node 22 LTS. This supersedes only the initial
Node 24.15.0 CLI floor in [the distribution decision](2026-10-13-cli-node-script.md).
Repository tooling keeps its existing Node baseline.

The CLI engine, esbuild target, early runtime guard and public installation docs
use this floor. Distribution tests cover versions below, at and above the boundary.
No publication or deployment is authorized by this runtime change.
