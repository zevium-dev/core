# Greenfield stack

> Date: 2026-07-12 · Status: accepted (built)
> Source: former root `TECH.md` "Stack decision"

## Decision

Rebuild on Convex (control plane + ledger truth), Cloudflare Worker (data plane: proxy, wallet DO, MCP), Clerk (auth, orgs, machine API keys), Stripe Checkout + Connect (top-ups, publisher payouts). Delete legacy tRPC + Drizzle/Turso + Better Auth + Polar.

## Why

Control/data plane split keeps the metered hot path at the edge; buy auth/payments/sync, own gating/metering/proxy/MCP. Full rationale: [architecture overview](../architecture/overview.md).

## Supersedes

Polar checkout + manual payouts. Wave 9 manual payout MVP ([2026-07-12-payouts-and-docs](2026-07-12-payouts-and-docs.md)) superseded by Stripe Connect.
