## CAUSE (ranked)

1. **Root `beforeLoad` always awaits `fetchConvexAuth` server fn** — `__root.tsx:42-43` + `27-36`. Every client nav pays Clerk server round-trip + JWT mint. Comment says SSR-only for token set, but **await still runs in browser**.

2. **`/app` `beforeLoad` always awaits `requireAuth` server fn** — `app.tsx:14-16` + `auth-session.ts:15-22`. Second Clerk server hop on every in-app nav. Parent stays matched but staleTime 0 → re-run.

3. **Projects loaders stack more server fns** — `projects/index.tsx:30-37` (`ensureMirrorOnServer` + `getAuthOrg` + Convex), `$projectSlug.tsx:55-62`, `spec.tsx:56+`. Worst path: root + app + leaf = 3–4 serial RPCs before paint.

4. **`defaultPreloadStaleTime: 0`** — `router.tsx:48`. Intent preload on hover wasted; click redoes work. Amplifies 1–3.

5. **`defaultViewTransition` 400ms** — `router.tsx:54-61` + `styles.css:146-171`. After loaders finish, another ~400ms morph. Stacks to “500ms+” feel even when data warm.

6. **No `defaultPendingMs: 0`** — old UI sticks during block; feels stuck rather than skeleton flash. Secondary UX, not primary latency.

**Not primary:** Sidebar Link type. Convex-in-component on dashboard/billing (non-blocking after commit). Settings leaves (no loaders).

**Why URL first, UI late:** location commits immediately; match stays `pending` until async `beforeLoad`/`loader` resolve. Default pendingMs hides pending UI → frozen old screen.
