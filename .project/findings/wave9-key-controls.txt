### Notes / design decisions
- **One-key rule vs rotation**: `createKey` still enforces one-active-key-per-user; `rotateKey` is a separate path that deliberately creates a 2nd Clerk key so the old one keeps verifying during grace. The gateway enforces the 24h cutoff via `graceUntil`; the old Clerk key remains revocable manually after switch-over (auto-revoke cron is out of scope).
- **Cap = settled paid credits only**: free-tier calls (0 credits) don't trip the cap. Counter keyed `settled:<keyId>:<YYYY-MM>`, bumps on settle, auto-resets at month rollover.
- **Propagation**: settings changes trigger a best-effort `/wallet/:org/sync-grants`; the DO's 60s sync window + lazy refresh bound staleness at ≤60s. Hot path stays Clerk/Convex-free in steady state.
